# Request links and QR codes

Handshake is a static prototype: each link under `https://handshake-exchange.pages.dev/#/exchange/<id>?request=...` contains a versioned snapshot of public exchange terms and can be opened in a clean browser without the creator's local storage. It carries currencies, payment methods, amounts, a partial-fill flag and a status snapshot; cash landmarks are excluded unless the sender explicitly opts in. It never includes ownership, provider identity, KYC, payment details, issue reports, settlement confirmations or other quotes. The fragment is not sent to the hosting server in an HTTP request, but anyone who receives the link can read and forward its contents. A link is not live availability, an authenticated order, a reservation, or a real trade coordinator: an `open` snapshot can become stale, and anyone can construct another snapshot. The checksum detects corruption, not forgery. Local imports must compare `requestFingerprint` as well as IDs and must not overwrite an existing order merely because its ID matches. Opening a link does not send a message or perform an exchange. QR codes encode the same public URL locally using the vendored MIT library; no third-party QR API receives the terms. Private Sites previews remain private, while shared request links open the public Cloudflare Pages snapshot.

## Browser API

- `buildRequestLink(order, {baseUrl?, includeAddress?, now?})` returns a deterministic URL for the same order terms. By default, it uses the public GitHub Pages root and omits cash addresses. When present, `order.createdAt` wins over the optional fallback `now`; no current timestamp is added implicitly.
- `parseRequestLink(hashOrURL)` returns `{id, give, receive, amount, minReceive, partial, snapshotStatus, createdAt?}` or `null` for invalid input. Cash endpoints have `address: ''` when a landmark was not shared. A receiving client must request a meeting landmark if required by a later local flow.
- `snapshotStatus` is one of `open`, `reserved`, `in-progress`, `completed`, `cancelled`. A new counter-request CTA is appropriate only for an `open` snapshot and must still explain that current availability is unverified.
- `requestFingerprint(record)` compares canonical public terms, including ID and snapshot status but excluding the creation timestamp. It is an exact comparison string, not a credential or signature.
- `createQRCode(url)` from `dist/qr-code.js` returns an SVG data URL for an `<img>` or a local `Image` rendered into the exported PNG. It uses error correction M and a four-module quiet zone. Typical links without an address are below 1,000 characters; optional long landmarks or unusual IDs can make them longer. The QR wrapper accepts at most 2,000 ASCII URL characters.
- `createOrderCard(order, {requestUrl?, includeAddress?, language?, now?})` optionally adds the local QR code and public site address to the downloaded PNG, and the full URL to its caption. It accepts only the canonical public root and verifies that the link matches the order terms and address-sharing choice; a link cannot silently disclose a landmark when `includeAddress` is false.

The v1 payload uses stable currency/bank/network/city values rather than catalog array positions. Amounts are positive finite numbers up to 1 billion, with up to six decimal places for USDT/USDC and two for fiat. Unsupported currencies, bank/currency combinations, networks, cities, malformed IDs, extra fields and invalid payload versions fail closed. A changed catalog can make an old snapshot unsupported; it must then be shown as unavailable rather than silently reinterpreted.

## Verification

`node --test tests/share-links.test.mjs` checks serialization, validation, privacy, status snapshots and SVG output. To additionally decode the rendered SVG with an independent implementation, set `HANDSHAKE_QR_DECODER` to the absolute path of the `dist/jsQR.js` CommonJS build from the [jsQR 1.4.0 npm package](https://www.npmjs.com/package/jsqr/v/1.4.0) and run the same command. The decoder is a development-only tool and is not shipped to browsers. This check was run successfully against two complete request URLs, including a longer Unicode cash landmark; the test rasterizes the exported SVG module rectangles and requires the decoded text to match the full URL exactly.
