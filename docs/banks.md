# Каталог банков Handshake

Проверено 15 октября 2026 года. Это выбранные способы расчёта для прототипа, а не рейтинг банков по активам, подтверждение партнёрства или обещание доступности переводов конкретному клиенту. Валюты в каталоге — поддерживаемое продуктом подмножество банковских услуг.

- Россия: Т-Банк, Альфа-Банк, Сбер, Яндекс Пэй, Райффайзен — набор пользователя, RUB.
- Армения: Ameriabank, Ardshinbank, Evocabank, ACBA, IDBank — набор пользователя, AMD/USD. EUR исключён по продуктовому требованию, хотя банки могут предлагать счета в EUR. Поддерживаемые AMD/USD присутствуют в [тарифах Evocabank](https://www.evoca.am/en/tariffs-for-commissions/accounts-tariffs/current-accounts) и [переводах Ardshinbank](https://ardshinbank.am/for-you/AMD/artpox?lang=en).
- Европа: только Revolut, EUR/USD. Wise оставлен с `legacy: true` для чтения старых записей и исключён из новых списков.
- Грузия: TBC Bank, Bank of Georgia, Liberty Bank, Basisbank, Credo Bank. Все пять присутствуют в [реестре Национального банка Грузии](https://nbg.gov.ge/en/licensed-commercial-banks). Для добавленных банков GEL/USD/EUR подтверждаются [тарифами Liberty](https://libertybank.ge/en/produqtebi/chemtvis/angarishebi-da-baratebi/angarishis-tarifebi), [тарифами Basisbank](https://bb.ge/en/personal/service-rates/personal-rates), [текущими счетами Credo](https://credobank.ge/en/products/current-account). Нумерация и порядок в интерфейсе не означают рейтинг.
- ОАЭ: Emirates NBD, First Abu Dhabi Bank, ADCB, Dubai Islamic Bank, Mashreq — пять выбранных розничных банков из [реестра CBUAE за август 2026 года](https://centralbank.ae/media/hw0lreyi/cb-register-august-2026.pdf), открытого через [страницу лицензирования CBUAE](https://centralbank.ae/en/licensing/). В прототипе все пять доступны в AED/USD. Основания: [Emirates NBD KFS](https://www.emiratesnbd.com/en/kfs/cash), [FAB Amana](https://www.bankfab.com/en-ae/islamic-banking/personal-islamic-banking/islamic-accounts/amana-islamic-account), [ADCB Foreign Currency Account](https://www.adcb.com/en/personal/accounts/current-savings-account/adcb-foreign-currency-account), [DIB Savings Account KFS, стр. 3](https://www.dib.ae/docs/default-source/cpr/kfs/Deposits-KFS-Savings-Account-SIA.pdf), [Mashreq Foreign Currency Accounts](https://www.mashreq.com/uae/neo/foreign-exchange/multi-currency-accounts/). Это может требовать отдельного валютного счёта; выбор банка не означает, что любая его карта принимает USD без конвертации.
- Казахстан: Halyk Bank, Kaspi Gold (Kaspi Bank), Банк ЦентрКредит, ForteBank, Alatau City Bank. Это подборка пяти банков для интерфейса, а не подтверждённая первая пятёрка по активам. Название Alatau City Bank заменило Jusan в 2025 году согласно [официальной истории банка](https://alataucitybank.kz/ru/history-bank); актуальное название также используется в [сообщении финансового регулятора о лицензиях Alatau и Forte](https://www.gov.kz/memleket/entities/ardfm/press/news/details/1257950?lang=ru). В каталоге Halyk/BCC/Forte/Alatau доступны в KZT/USD, Kaspi Gold — только KZT.

Валюты Казахстана проверены по [Halyk Bonus Digital](https://halykbank.kz/card/halyk-bonus-digital), [картам Банк ЦентрКредит](https://www.bcc.kz/personal/cards/), [Forte Solo Visa Signature](https://bank.forte.kz/ru/signature), [тарифам Alatau для физических лиц](https://alataucitybank.kz/file-server/filename?dir=documents&filename=tarify-ao-alatau-city-bank-na-uslugi-okazyvaemye-klientam---fizicheskim-licam-s-01-01-2026-ru.pdf). [Kaspi Gold FAQ](https://guide.kaspi.kz/client/ru/gold/receive/general/q46) не допускает мультивалютного счёта; [перевод с долларового депозита на Gold](https://guide.kaspi.kz/client/ru/bank/transfers/deposit/q1439) проходит с конвертацией. Поэтому USD-депозит Kaspi не используется как основание для USD в способе «Kaspi Gold».

`banksFor(currency, country?)` возвращает только доступные для нового выбора банки. `availableBankCountries(currency)` возвращает совместимые группы стран. `bankCountry(endpoint)` восстанавливает страну из ID банка, включая старые записи; поле `country` не меняет страну известного банка. Код `EU` обозначает группу «Европа» в интерфейсе.

`availableCurrencies(draft, side)` учитывает выбранный способ расчёта: валюты конкретного банка, USDT/USDC для криптовалюты, фиат для наличных; валюта второй стороны всегда исключена. Изменение `currency` не подменяет метод, банк или страну и отклоняет недоступное значение без изменения черновика. Изменения `bank`, `country`, `method` могут подобрать совместимую валюту из полного каталога. Если остаётся только валюта второй стороны, изменение отклоняется атомарно. В списке банков страны нужно показывать все её активные банки, включая банки с другим набором валют.
